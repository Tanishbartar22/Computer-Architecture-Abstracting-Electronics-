In computation, we borrow from information theory, along with many axioms, rules, and structures from other domains. Computation then builds rules and axioms to modify or transform representations from information theory when objects undergo operations. You can imagine it like this: let’s say we are adding three numbers in binary (B1, B2, B3). The operation looks like B1 + B2 + B3. Computation has rules that transform combinations, in a certain encoding, based on the operation and the objects to find the answer. That is abstract computation. Now, we can talk about the physical interpretation of computation. This is where we begin to discuss how computers work.

The physical interpretation of computation can be explained in two parts:

1. The first major aspect of the physical interpretation of computation is actually performing the operations that exist in abstract computation: changing the combinations based on the operations and storing the result in storage itself. To do that, the machine needs to physically read those combinations as voltages, which also requires the physical form of information theory.
    
2. It is responsible for changing or accessing the physical interpretation of information theory. In the physical interpretation of information theory, we have a long collection of electronic storage units representing 0s and 1s. One idea of computation is to modify that physical representation.
    

The interesting part is that, for the machine to do either of the above, it needs to read a set of voltages, representing 0 or 1, or a combination of voltages. These voltages are stored in physical storage—the physical form of information theory. These combinations of voltages are called computer instructions or binary instructions.

The memory, physical storage, or physical form of information theory that we use in computation is actually a special architecture, since computation deals with operations from many sciences—mathematics, logic, languages, and so on. Here, the same bits can represent objects from different sciences. Since computer instructions are also stored here, we also have instructions represented by bits. It is up to the machine how it interprets the bits. Let’s say we give the computer a set of instructions to add 2 and 3 and store the result in memory. Our last instruction will specify where we want that 5 to be stored, and perhaps, at a different location, we store the location of this result so that we can use it again. Physically, we do have the physical implementation of information theory, but in the same physical storage, we have instructions, memory locations, and so on, which are not conventional objects that we use information theory to represent.

What we can say is that memory addresses, variable names, locations, and computer instructions are not from an external domain, as you mentioned. Instead, they exist because they are important for operations from external domains to happen and because they make it easier to instruct computers, for example through variable names.
